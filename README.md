This is random cats! I think things are better with cats involved, so why not make a webpage for people who like pictures of random cats? This project uses vanilla HTML, CSS, and JS alongside The Cat API and a mix of Flexbox and CSS Grid methodology. The page fetches a random cat image and provides two voting options: do you like or dislike this cat? Users who choose to like these creatures can then visit a gallery of cats they favored. Overall, this project is a showcase of simple web development principles that come together as a cohesive project, with a simple UI, dynamic items, and the usage of key browser features such as localStorage.

To run this, ensure you have Python installed. It's used to host the webpage locally.

Then run the included start-server.bat file, and open your browser to http://localhost:8080.

Additionally, you can enter your Cat API key in its respective field in main.js (YOUR_API_KEY) IF you want to retrieve cat breed data for alt text. But it's not required to fetch images alone. 

You're set to look at some cats!
